# Demo Script

## Setup

1. Deploy `HabitMakerCommitments`.
2. Start the agent.
3. Start the demo app.
4. Set the demo contract address to the deployed address.
5. Connect a funded wallet on the target chain.

## Live Flow

1. Enter a goal such as `I want to work out 3 times a week and stay accountable`.
2. Click `Plan commitment`.
3. Review the proposed cadence, target, suggested stake, and proof policy.
4. Click `Create commitment` and sign the transaction.
5. Inject one or more mock evidence snapshots.
6. Click `Get recommendation`.
7. Review the returned explanation and prepared action.
8. Sign the recommended action.
9. Refresh the onchain state and show the updated commitment status.

## What To Emphasize

- The user controls the wallet and signs final actions.
- The agent contributes structure, interpretation, and recommendations.
- The commitment terms are enforced onchain.
- Multiple health signal sources can feed a shared evidence model.
