# Habit Maker Agent

Standalone HTTP service for planning commitments, storing mock evidence, recommending actions, and preparing contract calls.

## Endpoints

- `GET /health`
- `POST /plan-commitment`
- `POST /evidence/mock`
- `POST /recommend-action`
- `POST /prepare-action`

## Scripts

```bash
pnpm install
pnpm dev
pnpm test
```
